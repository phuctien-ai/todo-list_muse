# Todo List

Ứng dụng todo list đơn giản bằng HTML / CSS / JavaScript thuần, lưu dữ liệu ở localStorage.

## Cách chạy trong VS Code

1. Clone repo này về máy
2. Mở thư mục trong VS Code
3. Mở file `index.html` bằng Live Server (hoặc mở trực tiếp bằng trình duyệt)

## Lịch sử tính năng (học cách làm việc với GitHub)

- Bước 1: Thêm công việc
- Bước 2: Sửa công việc
- Bước 3: Xóa công việc
